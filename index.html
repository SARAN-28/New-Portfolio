Featured project

Employee Management Portal (E-Clocker)

GitHub repository

A role-based (Admin/Employee) workforce management system with separate dashboards, permissions and API access levels for each role.

What it does

  • Role-based Admin and Employee access
  • Email invitation flow (Crypto + Nodemailer) that creates the employee profile and initial leave balances on signup
  • Clock-in/out with image and geo-location capture stored on AWS S3
  • Missed-punch regularization and total/effective hours tracking
  • Weekly timesheets with task-level entries, validated against attendance hours, with admin approve/reject
  • Leave and comp-off management with week-off/holiday-aware validation and balance calculation
  • Announcement feed with likes, comments and pagination, plus scheduled reminders using node-cron
  • JWT authentication and OTP-based 2FA for admin
  • Sequelize/MySQL schema with 20+ tables, cascading deletes and unique constraints
